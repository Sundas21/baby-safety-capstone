
# Baby Safety Capstone

AI-powered monitoring system to ensure baby safety and provide real-time alerts to parents.

## Tech Stack
- Frontend: React + TypeScript
- Backend: Node.js + Express
- AI: Claude API for assistance
- Tools: Git, GitHub, VS Code

## Setup
1. Install Node.js LTS
2. Clone repo: git clone https://github.com/Sundas21/baby-safety-capstone.git
3. npm install
4. npm run dev
